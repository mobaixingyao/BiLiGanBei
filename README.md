# BiLiganbei — 哔哩哔哩视频下载器

一款基于 **Python + PySide6** 开发的哔哩哔哩（Bilibili）视频下载桌面应用，支持二维码登录、视频查询、UP 主投稿查看、合集/收藏夹批量下载以及多任务队列下载。

---

## 功能特性

- **二维码登录**：扫码登录后自动保存登录状态，避免重复登录
- **视频查询**：输入 BV 号或视频链接查看视频详情、分 P 信息、可用清晰度
- **UP 主视频**：输入 UID 查看 UP 主所有投稿，支持翻页、封面预览、批量下载
- **合集 / 收藏夹下载**：
  - 输入视频 BV 号/链接自动获取所属合集
  - 输入收藏夹 ID 或收藏夹链接（如 `https://space.bilibili.com/xxx/favlist?fid=123456`）下载整个收藏夹
- **下载任务管理**：独立的下载页面，支持任务队列与并发控制（最多 3 个同时下载）
- **清晰度选择**：支持 360P ~ 4K/HDR 等多种清晰度
- **自动合并**：音视频分离下载后通过 ffmpeg 自动合并为 MP4
- **弹幕下载**：下载视频时自动获取弹幕，支持 ASS 字幕（含滚动动画、位置、颜色）和 XML 两种格式，可在设置中切换
- **文件夹管理**：每个视频独立子文件夹，视频与弹幕文件统一存放
- **本地配置**：登录状态、下载目录、默认清晰度、并发数等自动保存

## 运行环境

- Windows 10 / 11
- Python 3.9+
- 已安装 ffmpeg（下载合并必需）

---

## 安装

1. 克隆仓库

```bash
git clone https://github.com/mobaixingyao/BiLiganbei.git
cd BiLiganbei
```

2. 创建虚拟环境并安装依赖

```bash
python -m venv .venv
.venv\Scripts\activate
pip install PySide6 requests qrcode pillow
```

3. 确保 ffmpeg 已添加到系统 PATH

```bash
ffmpeg -version
```

4. 启动程序

```bash
python bilibili_downloader.py
```

## 使用说明

### 1. 登录

- 打开程序后，在「设置」中点击「二维码登录」
- 使用手机哔哩哔哩 App 扫码
- 登录成功后状态会自动保存到 `config/login_state.json`

### 2. 下载单个视频

- 切换到「视频查询」页面
- 输入 BV 号或视频链接，点击「查询」
- 选择清晰度后点击「下载」

### 3. 批量下载 UP 主视频

- 切换到「UP 主视频」页面
- 输入 UP 主 UID，点击「查询」
- 选中需要的视频或直接点击「全部下载」

### 4. 下载合集 / 收藏夹

- 切换到「合集/收藏夹」页面
- 输入视频链接/BV 号获取所属合集
- 或输入收藏夹 ID / 收藏夹链接获取收藏夹视频
- 支持分页浏览与批量下载

### 5. 管理下载任务

- 切换到「下载任务」页面
- 可查看下载进度、排队数量、同时下载数
- 在「设置」中可调整并发下载数（1~3）

### 6. 弹幕下载

- 在「设置」中勾选「下载视频时同时下载弹幕文件」即可开启（默认开启）
- 在「弹幕格式」下拉框中选择格式：
  - **ASS 字幕**：含滚动动画、位置、颜色、字号，样式参照 B 站官方 ASS 导出（黑体半透明、Fix+R2L 双样式）
  - **XML**：B 站标准 XML 弹幕格式，兼容原始弹幕文件用途
- 下载视频后自动通过 B 站 protobuf 弹幕接口 (`/x/v2/dm/web/seg.so`) 获取弹幕
- ASS 格式兼容主流播放器（PotPlayer、mpv、VLC、MPC-HC 等）
- 下载目录结构如下：

```text
downloads/
└── 视频标题/
    ├── 视频标题.mp4    # 视频文件
    └── 视频标题.ass    # 弹幕字幕文件 (或 .xml)
```

## 技术栈

- **GUI**: PySide6
- **网络请求**: requests
- **WBI 签名**: 自定义签名实现
- **音视频合并**: ffmpeg
- **二维码生成**: qrcode
